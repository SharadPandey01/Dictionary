**📘WordForge**: _Forge Your Vocabulary_
****************
A full-stack dictionary web application built using React, Node.js, Express, and MongoDB.
Users can search for word meanings, save words, view word of the day, and explore random vocabulary.

**🚀 Features**

🔍 Search any English word

📖 View definition, part of speech, example, synonyms & antonyms

💾 Save words to personal collection

🗑 Remove saved words

🎲 Random word generator

🌅 Word of the Day

🎨 Responsive UI with Tailwind CSS

⚡ Full-stack architecture with REST API

********
🏗 **Tech Stack**
********

**_FRONTEND_**


React

React Router

Tailwind CSS

Fetch API


**_BACKEND_**


Node.js

Express.js

MongoDB

Mongoose

****
**API EndPoints**
****
| Method | Endpoint               | Description           |
| ------ | ---------------------- | --------------------- |
| GET    | `/api/define/:word`    | Get word meaning      |
| GET    | `/api/random`          | Get random word       |
| GET    | `/api/word-of-the-day` | Get saved random word |
| GET    | `/api/mywords`         | Get saved words       |
| POST   | `/api/mywords`         | Save word             |
| DELETE | `/api/mywords/:id`     | Delete saved word     |

**_EXTERNAL API_**

Free Dictionary API : 
https://dictionaryapi.dev/
